# CF-AR2-GOLDEN-HARNESS-01 — test-transition classification (DO item 4/6)

Full per-file classification of every pre-existing test file under
`lib/analyzer/**/*.test.ts` and `scripts/evidence/**/*.test.ts` (124 files;
the 3 new files this outcome adds under `lib/analyzer/golden/` are this
outcome's own harness, not classified here), referenced from the main PR
draft (`docs/superpowers/plans/ar2-golden-harness-pr-draft.md`) rather than
inlined there for size. "encodes a ruling" = keep as-is, untouched by this
outcome. "PINS AN OUTPUT" = a candidate to be replaced by an invariant in
AR3+ — not touched, not loosened, not deleted by this outcome either; DO
NOT forbids any of that here.

`lib/analyzer/acquisition/msftStage2ValuationProof.test.ts`,
`lib/analyzer/modules/reverseDcf.test.ts` (its GOLDEN block specifically —
the rest of that file encodes real rules and stays), and
`lib/analyzer/modules/reverseDcf.independentVerification.test.ts`. The
other 120 files encode a rule, a gate, a suppression state, or a sourced
fact's extraction — not a solved valuation number — and are classified
